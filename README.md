# 🧊 REVOLVE - Simulador de Sólidos de Revolución

**Proyecto Integrador · Cálculo Integral · Ingeniería de Sistemas**

## 📝 Descripción
Aplicación web interactiva que modela y calcula el volumen de sólidos de revolución
mediante los métodos de **Discos**, **Arandelas** y **Cascarones Cilíndricos**.
Incluye visualización 3D, cálculo simbólico exacto, aproximación numérica y un
asistente paso a paso con narración por voz.

## 🎯 Ejemplos contextualizados (Ingeniería de Sistemas)
1. **Discos** — Microlente parabólica de acoplamiento de fibra óptica
2. **Arandelas** — Funda cónica de cable de fibra óptica
3. **Cascarones** — Base ondulada de hub IoT impresa en 3D

## 🚀 Cómo usar
1. Abre `index.html` en tu navegador (Chrome, Firefox o Edge)
2. No requiere servidor ni instalación
3. Funciona 100% offline
